# Online Retail Transaction Data Analysis & Customer Segmentation

## 📌 Project Overview
This project focuses on analyzing a real-world online retail transaction dataset to extract meaningful insights about customer behavior and product relationships. The dataset contains invoice-level transactions including product details, quantities, prices, customers, and countries.

The project demonstrates practical data science techniques such as data preprocessing, exploratory data analysis, clustering, association rule mining, and classification modeling.

---

## 📊 Dataset Description
The dataset includes the following features:
- InvoiceNo: Unique invoice number
- StockCode: Product identifier
- Description: Product name
- Quantity: Number of items purchased
- InvoiceDate: Date and time of transaction
- UnitPrice: Price per unit
- CustomerID: Unique customer identifier
- Country: Customer’s country

---

## 🧹 Data Preprocessing
- Handling missing values
- Removing invalid transactions
- Feature scaling using StandardScaler and MinMaxScaler
- Encoding categorical variables (Label Encoding, One-Hot Encoding)
